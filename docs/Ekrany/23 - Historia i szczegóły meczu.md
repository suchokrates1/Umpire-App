# Historia i szczegóły meczu

## Cel

Przegląd lokalnie zapisanych meczów (Room) i ich szczegółów / usuwanie.

## Kiedy się pojawia

Z [[22 - Ustawienia]] → karta Historii.

## Historia meczów

| Kontrolka | Co robi | Efekt |
|-----------|---------|-------|
| Tytuł **Historia meczów** | — | — |
| Karta meczu (gracze, wynik, zwycięzca, data, czas, kort) | Otwórz szczegóły | → Szczegóły |
| Ikona **Usuń mecz** | Potwierdzenie | Usuwa jeden wpis |
| Menu **Usuń wszystkie** | Potwierdzenie | Czyści całą historię |
| Pusty stan **Brak zapisanych meczów** | — | — |

Dialogi:
- **Usuń mecz?** → **Tak** / **Anuluj**
- **Usunąć wszystkie mecze z historii?** → potwierdzenie

## Szczegóły meczu

| Element | Zawartość |
|---------|-----------|
| Tytuł **Szczegóły meczu** | — |
| Treść scroll | Gracze, wynik setów, kort, start, czas trwania, sędzia, zwycięzca, historia setów (TB/STB), linie statystyk |
| Brak danych | **Nie znaleziono szczegółów meczu** |
| Up | Powrót do listy |

> [!note] Lokalność
> To historia na urządzeniu sędziego, nie pełny panel biura na stronie.

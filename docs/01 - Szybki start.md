# Szybki start — dzień turnieju

> [!tip] Dla kogo
> Sędzia na korcie. Zakłada działający backend i PIN kortu z panelu Admin.

## Kolejność

1. Uruchom aplikację → [[10 - Wybór języka]] (tylko przy pierwszym starcie lub zmianie języka).
2. [[11 - Wybór turnieju]] — wybierz aktywny turniej dnia.
3. [[12 - Wybór kortu]] — stuknij swój kort.
4. [[13 - Autoryzacja PIN]] — wpisz 4-cyfrowy PIN (auto-wysłanie po 4. cyfrze).
5. [[14 - Wybór zawodników]] — zaznacz 2 (singiel) lub 4 (debel); ewentualnie użyj sugerowanego meczu z planu.
6. [[15 - Konfiguracja meczu]] — format, sędzia, tryb Basic/Advanced → start.
7. [[17 - Wybór serwującego]] — kto serwuje pierwszy (opcjonalnie zamiana stron).
8. Punktuj: [[18 - Tryb Advanced - serwis i wymiana]] albo [[19 - Tryb Basic]].
9. Reaguj na [[20 - Komunikaty (zmiana stron, TB, DP)]].
10. Po meczu: [[21 - Koniec meczu i powody zakończenia]] → następny mecz tym samym setupem lub nowym.
